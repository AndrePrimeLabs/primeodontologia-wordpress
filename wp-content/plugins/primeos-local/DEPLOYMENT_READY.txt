STEP 1: Prepare Local Environment
  └─ npm run build
  └─ Verify dist/ created

STEP 2: Configure DNS (Hostinger)
  └─ Add A record: primeos → 82.29.56.236
  └─ TTL: 3600
  └─ Wait 5-30 minutes for propagation

STEP 3: Edit Production Environment
  └─ cp .env.example .env.production
  └─ Edit with your values:
     - ACME_EMAIL (for SSL)
     - Supabase credentials
     - Firebase credentials
     - API keys

STEP 4: Initial VPS Setup (One-time)
  └─ ./scripts/deploy-vps.sh 82.29.56.236 root setup
  └─ Installs Docker, Docker Compose
  └─ Creates project directory

STEP 5: Deploy to VPS
  └─ ./scripts/deploy-vps.sh 82.29.56.236 root deploy
  └─ Builds locally
  └─ Copies to VPS
  └─ Starts services
  └─ Traefik provisions SSL cert (2-3 min)

STEP 6: Verify Deployment
  └─ ./scripts/deploy-vps.sh 82.29.56.236 root status
  └─ curl https://primeos.primeodontologia.com.br/health
  └─ Visit in browser
